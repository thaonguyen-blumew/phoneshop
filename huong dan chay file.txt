HUONG DAN CHAY PIPELINE PHONE SHOP

1. Kien truc tong the

OLTP MySQL -> mock_excel.py -> staging -> DWH -> Power BI

Y nghia:
- OLTP: co so du lieu giao dich goc
- mock_excel.py: sinh 2 file Excel phuc vu phan tich
- staging: lop trung gian, nhan du lieu tho
- DWH: kho du lieu phan tich
- Power BI: dung DWH de lam dashboard

2. Cac file can nho

- init_oltp.sql: tao database OLTP
- data.sql: nap du lieu ban dau vao OLTP
- backfill_oltp.py: sua du lieu san pham/variant neu can
- mock_excel.py: sinh / cap nhat 2 file Excel mock
- staging/phoneshop_stg_schema.sql: tao schema staging
- dwh/phoneshop_dw_target_schema.sql: tao schema DWH
- etl_target_pipeline.py: noi chua logic ETL that
- run_daily_pipeline.py: file runner cho Task Scheduler

7. Cach chay daily bang Windows Task Scheduler

Task neu da tao se co dang:
- Ten task: PhoneShopDailyPipeline
- Gio chay: 10:00 PM

Task nay nen goi file run_daily_pipeline.py.

Neu muon xem lai:
- Mo Task Scheduler
- Vao Task Scheduler Library
- Tim task ten PhoneShopDailyPipeline
- Xem tab Triggers de biet gio chay
- Xem tab Actions de biet no dang goi file nao
- Xem tab History neu muon biet da chay hay chua

Quan trong:
- Neu may con bat va dang ngu, task co the chay
- Neu may shutdown hoan toan, task KHONG chay duoc luc 02:00
- Neu muon task chay trong luc may tam tat man hinh, nen dung Sleep thay vi Shutdown
- Neu ban muon may van tat vao ban dem, can chuyen pipeline sang may chu / laptop always-on / server khac

8. Cach xu ly neu bo qua gio chay

Task Scheduler co the duoc cau hinh de:
- chay ngay khi may bat len neu da qua gio
- chi chay khi co ket noi phu hop

Nhung neu may da shutdown, no van phai doi den khi may duoc bat len moi chay duoc.
